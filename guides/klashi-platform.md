# Klashi Platform — Betting Workflow Guide

## Account Setup Checklist

- [ ] Deposit funds and verify payment method
- [ ] Enable two-factor authentication
- [ ] Set responsible gambling deposit limits
- [ ] Bookmark the live-odds page for your primary sports
- [ ] Enable push notifications for line movement alerts (if available)

## Navigating Klashi

### Locating Lines
1. Select sport from the top navigation bar
2. Choose **Today** or a specific date from the calendar
3. Games display with moneyline, spread, and total side-by-side
4. Click any odds to add to your bet slip

### Bet Slip Best Practices
- Review the line one final time before confirming — Klashi may move the line after you click
- Use **"Request Bet"** if your intended wager size is above the standard limit
- For parlays, add legs before opening the slip to see combined odds update in real-time

### Live Betting on Klashi
- Access via the **"Live"** tab in the top navigation
- Lines update in near-real-time; confirm odds are still displayed before submitting
- Half-time and quarter-time windows offer reset-state value — see `analysis/line-movement.md`

## Order Types

| Type | When to Use |
|------|-------------|
| Standard Bet | Pre-game, normal sizing (1–2 units) |
| Request Bet | Large wager (3 units) — Klashi may counter |
| In-Play Bet | Live game, confirmed edge on momentum shift |
| Parlay | 2–3 legs max, 0.5 unit total exposure |
| Same-Game Parlay | Avoid — heavy juice built into correlations |

## Claiming Promotions

- **Reload bonuses**: Check the Promotions tab weekly; favor cash-out bonuses over free-play
- **Odds boosts**: Only use when the boosted line is already a pick — never force a bet for the boost
- **Refer-a-friend**: Stack referral credits into your unit bankroll slowly

## Withdrawal Best Practices

- Withdraw profits on a set schedule (e.g., every month-end) to lock in gains
- Never withdraw from your base bankroll mid-month — it distorts unit sizing
- Keep a buffer above your base bankroll to absorb variance

## Customer Support

- Use live chat for any bet void or settlement disputes
- Screenshot disputed bets immediately after placing — include timestamp and odds
- Escalate unresolved disputes after 48 hours

## Responsible Gambling

Klashi offers:
- **Deposit limits** — set weekly/monthly caps
- **Cool-off periods** — take a forced break if running hot or cold
- **Self-exclusion** — nuclear option, 30/90/180 days

If you are chasing losses, stop for the day. No single bet fixes a bad week.
