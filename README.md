# Trade-desk — Sports Betting Research Hub

A private knowledge base for disciplined, data-driven sports betting on the **Klashi platform**. Every pick is documented, every result recorded, and every edge tracked.

## Philosophy

> "The goal is not to pick winners. The goal is to find bets where the probability of winning exceeds the implied probability in the price."

Winning long-term requires:
- **Positive expected value (+EV)** on every wager
- **Consistent unit sizing** based on Kelly Criterion
- **Rigorous record keeping** — no selective memory
- **Line shopping** — always get the best number available

## Quick-Start Workflow

### 1. Check the daily slate
Open Klashi, navigate to your target sport, and note opening lines.

### 2. Do your research
- Injuries: official team injury reports + beat reporters on X/Twitter
- Line movement: compare Klashi's current number to the opening line
- Public betting %: fade heavy public sides (>70%) when sharp action disagrees

### 3. Identify your edge
Refer to `guides/value-betting.md` to calculate your true win probability.  
If your edge is <2%, pass. If ≥2%, size using Kelly (see `guides/bankroll-management.md`).

### 4. Place the bet on Klashi
Follow the workflow in `guides/klashi-platform.md` for optimal order entry.

### 5. Log the pick
Copy `picks/template.md` into the correct month file and fill it in before the game starts.

### 6. Record the result
Update `picks/2026/tracking.md` after the result is final.
